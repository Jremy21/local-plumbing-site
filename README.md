# Local Plumbing Site

Professional static website for a residential plumbing business, built as a clean multi-page marketing site with focused service content and contact flows.

## Overview

This project includes a custom homepage, dedicated services page, About Us page, Contact Us page, success page, shared styling, and lightweight frontend interactions. The site is designed around a local plumbing brand and emphasizes trust, service clarity, and direct customer contact.

## Pages

- `index.html` - homepage with hero section, service request form, proof section, and FAQ
- `services.html` - service detail page for leak repair, drain cleaning, and installations
- `about.html` - company background and local business positioning
- `contact.html` - contact information page with service area and expectations
- `success.html` - simple confirmation page

## Assets

- `style.css` - shared site styling and responsive layout rules
- `script.js` - scroll reveal behavior and lightweight page interactions
- `Images/` - site photography and visual assets

## Design Direction

- Dark, high-contrast brand presentation
- Clear calls to action for phone and service requests
- Dedicated interior pages for navigation clarity
- Plumbing-specific imagery and service language
- Responsive layout suitable for desktop and mobile viewing

## Usage

Open `index.html` in a browser to preview the site locally.

## Project Type

Static HTML, CSS, and JavaScript website.
